# ALAS — сайт премиального клининга с обрядом «Аластау»

Next.js 16 (App Router) + Tailwind CSS v4 + Motion (Framer Motion) + Lenis.
Полная дизайн-спека, копирайтинг и чек-лист съёмки: `docs/alas-frontend-spec.md`.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # продакшн-сборка
npm run lint       # eslint
npm run typecheck  # tsc --noEmit
npm run fonts:check # у каких шрифтов есть подсет cyrillic-ext (казахские глифы)
```

## Что уже работает

- Единая дизайн-система в токенах: `src/app/globals.css` (палитра, радиусы, тени, кривая анимаций).
- Инверсия темы по скроллу: секции с `data-theme-zone="night"` гасят сайт в обсидиан.
- Калькулятор на ваших тарифах (650 / 650 / 800 ₸ за м², балкон, все допы, обряд «Аластау»)
  с живой сметой, анимированным итогом и оценкой времени и состава команды.
- Сквозной WhatsApp-слой на `8 707 306 75 76`: шапка, Hero, плавающая кнопка, мобильный бар,
  «Отправить смету в WhatsApp», блок «Не хочется считать самому?». Все ссылки собираются через
  `waLink()` с разметкой источника для аналитики.
- Бронирование: выбор даты и времени, форма — заявка уходит готовым текстом в WhatsApp.
- Секция «Аластау» с дымом по скроллу, интерактивное «До/После» (линза), команда, чек-лист,
  химия, отзывы, гарантии, прайс, FAQ с JSON-LD, финальный CTA.
- Стайлгайд для приёмки: `/dev/type` — казахские глифы, палитра, кнопки.

## Что нужно заменить перед запуском

| Что | Где | Чем |
| --- | --- | --- |
| Плейсхолдеры съёмки (`MediaSlot`) | секции услуг, «Аластау», команда | своими фото и видео, ТЗ на кадр написано внутри каждого слота |
| CSS-слои в «До/После» | `src/components/ui/LensCompare.tsx` | парами фото с одного штатива через `next/image` |
| Отзывы, кейсы, команда | `src/components/sections/*` | реальными данными, затем перенести в Firebase |
| Свободные слоты в Hero | `HeroSection.tsx` | данными из Firebase |
| Цена опции «Аластау» при влажной уборке | `src/lib/pricing.ts` → `ALASTAU_OPTION_PRICE` | сейчас `null` («уточним»); подставить число, когда решите |
| Реквизиты, БИН, политика | `src/lib/company.ts` + `/privacy` | заполнить `iin` и `email` перед публикацией |
| GA4 / Яндекс.Метрика | `.env` → `NEXT_PUBLIC_GA_ID`, `NEXT_PUBLIC_YM_ID` | см. `docs/analytics-setup.md` |

## Структура

```
src/
├─ app/                  layout, globals.css, главная, /dev/type
├─ components/
│  ├─ sections/          секции главной страницы сверху вниз
│  ├─ calculator/        стор сметы, чек, бронирование
│  ├─ contact/           WhatsApp-кнопка, FAB, мобильный бар
│  ├─ layout/            шапка, футер, логотип
│  ├─ providers/         Lenis, инверсия темы
│  └─ ui/                Reveal, LensCompare, AnimatedNumber, MediaSlot
└─ lib/                  тарифы, контакты, шрифты, motion, аналитика
```

Тарифы правятся в одном месте — `src/lib/pricing.ts`. Калькулятор, прайс и карточки услуг
читают их оттуда, руками цифры больше нигде не проставлены.
